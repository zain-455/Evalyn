# Evalyn — Psychometric Adaptive Testing & Behavioral Analytics System

> **Status: Active Development** — Final Year Project (FYP) | ~60% Complete

## Overview
Evalyn is a full-stack web-based adaptive examination platform combining Item Response 
Theory, behavioral integrity monitoring, and AI-assisted question generation to deliver 
a psychometrically grounded online testing experience.

## Tech Stack
| Layer | Technology |
|---|---|
| Backend | ASP.NET Core 10 Web API, Entity Framework Core 10 |
| Frontend | React 18, Vite 6 |
| Database | SQL Server |
| AI | Google Gemini 1.5 Flash |
| ML | ML.NET 4.0.2 (Randomized PCA) |

## Features

**Completed**
- IRT-based Computerized Adaptive Testing with MAP/MLE theta estimation
- JWT authentication with role-based access control
- AI-assisted MCQ generation from topic prompts
- Behavioral integrity monitoring (7-dimensional feature vector)

**In Progress**
- Psychometric analytics dashboards
- JMLE item calibration pipeline

## Project Status
This project is currently under active development as part of a Final Year Project. 
Core examination and authentication flows are complete. Analytics and calibration 
pipelines are in progress.
